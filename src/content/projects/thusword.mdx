## About

Thusword is a once-a-day word game: a freeform crossword you solve through
**progressive reveal**. You start with two clues; solving a word unlocks the
words that cross it — with the shared letters pre-filled — until the whole grid
is solved. Everyone plays the same puzzle each day, and a streak rewards coming
back.

## Notable

- A pure, testable **reveal engine** driven by `useReducer`, kept entirely
  separate from the UI.
- Daily puzzles are generated **offline** and committed as JSON — the app just
  plays them, so there's no puzzle backend to run.
- A real-time **co-op mode** lets two people solve together, with its own
  grid-reveal choreography.
- Covered by Playwright **end-to-end and visual tests**, plus row-level-security
  checks on the data layer.

## Stack

Vite + React 19 + TypeScript + Tailwind 4, deployed as a static site to GitHub
Pages, with Supabase backing streaks and co-op.
