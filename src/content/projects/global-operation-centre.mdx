## About

The Global Operation Centre ("the GOC") is a data-visualisation application
built at **Firmus Technologies** to support the teams that keep infrastructure
running: on-call engineers, operations-centre support staff, and field service
technicians. It turns operational data into views each of those teams can act
on. As an internal tool it isn't publicly accessible; the link points to Firmus'
infrastructure work for context.

## Notable

- Built the interface against an **established design system** authored in Figma,
  integrating its components and following the team's UI/UX guidelines.
- Developed and documented components in **Storybook**, so each was visualised
  and reviewable in isolation.
- Covered the app with **unit and integration tests** in Vitest and end-to-end
  tests in Playwright.
- Shipped through a full **CI/CD pipeline**: peer dev reviews plus automated
  Jenkins builds.
- Worked in a hybrid **scrum/kanban** process in Jira, with weekly team-lead
  replenishment and regular retrospectives.

## Stack

React + TypeScript on the front end, Python services behind it, a Figma-based
design system realised in Storybook, tested with Vitest and Playwright, and
delivered via Jenkins CI/CD.
