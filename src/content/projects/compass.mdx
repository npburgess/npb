## About

Compass is the platform behind **Cycle Inspect** — software for booking, running,
and reporting bicycle inspections. It's my day job, so the live product sits
behind a login; the link goes to the marketing site.

## Notable

- **Role-scoped access** so inspectors, admins, and clients each see the right
  data (Supabase auth + row-level security).
- Data-dense **dashboards** (TanStack Table + Recharts) and generated **PDF
  inspection reports** (`react-pdf`).
- Forms built with react-hook-form + Zod, on Radix UI primitives.
- Some AI-assisted workflows via OpenAI; transactional email via Resend.

## Stack

Next.js 15 + TypeScript, Supabase (auth / Postgres / SSR), TanStack Query &
Table, Recharts, react-pdf.
