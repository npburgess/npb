## About

Keiron's Krafts is an online storefront for handmade goods, a clean shop that's
straightforward for its owner to run day to day.

## Notable

- Product and order data in **Postgres (Neon)** via **Drizzle ORM**, typed end to
  end.
- Image uploads to **S3** with presigned URLs.
- Generated **PDF** invoices/receipts (`react-pdf`) and transactional email
  (Resend).
- Cart and UI state handled with Zustand.

## Stack

Next.js + TypeScript, Postgres (Neon) + Drizzle ORM, AWS S3, Resend.
